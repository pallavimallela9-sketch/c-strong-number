# Strong Number

This program checks whether a given number is a strong number or not.

## Features

* Takes a number from the user
* Finds the factorial of each digit
* Calculates the sum of factorials
* Checks whether the number is strong

## Technology Used

* C

## Concepts Used

* Functions
* Variables
* While loop
* For loop
* Conditional statements
* Modulus operator

## Sample Output

```text
Enter a number: 145
145 is a strong number.
```
